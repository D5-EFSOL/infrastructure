# SelfPortal — портал самостоятельной смены пароля Windows

Веб-приложение на IIS (ASP.NET Web Forms, C#) для самостоятельной смены
пароля пользователем, в том числе **истёкшего**. Две версии:

- **Локальная** (`selfportal_local/`) — смена пароля **локальных** учётных
  записей на сервере без домена.
- **Доменная** (`selfportal_AD/`) — смена пароля **доменных** учётных записей
  Active Directory.

Обе версии разворачиваются на RDS-шлюзе (IIS прямо на сервере) и работают
публично в интернете.

---

## История версий

### 1.1 (текущая)

Новые возможности интерфейса и улучшения безопасности:

**Функциональность**
- Подсказка о политике сложности перед полем «Новый пароль» («не менее N
  символов», «символы трёх из четырёх категорий»). Читает **реальную**
  политику: локальная версия — локальный SAM (`samlib.dll`), доменная —
  атрибуты корневого объекта домена (`minPwdLength`, `pwdProperties`).
- Динамическая проверка при наборе нового пароля: шкала прогресса и чек-лист
  (длина, заглавные/строчные буквы, цифры, спецсимволы) с зелёными галочками.
- «Глазок» на всех парольных полях — показать/скрыть вводимые символы.
- Вся клиентская логика вынесена во внешний `selfportal.js` (совместимо с CSP,
  запрещающим inline-скрипты).

**Безопасность и надёжность**
- Проверка сложности нового пароля по **реальной политике** сервера/домена
  (Win32 `NetValidatePasswordPolicy`) вместо захардкоженного набора правил.
- Отключение рециклинга пула IIS (idle-timeout + periodic restart) в
  deploy-скрипте — счётчики блокировок в памяти процесса больше не
  сбрасываются раньше истечения.
- Исправлен битый `defaultRedirect="/error.htm"` (вёл на несуществующий файл).

**Деплой**
- Deploy-скрипт копирует `selfportal.js`.
- Параметризация `-ClientName` и `-Port` через аргументы командной строки.

### 1.0

Первый релиз. Обе версии (локальная и доменная) с базовой логикой:

**Логика смены пароля**
- Смена пароля через WinNT-провайдер `ChangePassword(старый, новый)` —
  аутентифицируется старым паролем, не требует прав администратора, работает
  для истёкшего пароля.
- Локальная версия: `WinNT://./<user>,user`; доменная: `WinNT://<домен>/<user>,user`.
- Доменная версия проверяет членство сервера в домене.

**Защита от перебора**
- CAPTCHA после первой неудачной попытки.
- Блокировка по IP: 5 попыток → 30 минут.
- Блокировка по учётной записи: 10 попыток → 60 минут.
- Счётчики в `MemoryCache`.

**Защита административных учётных записей**
- Запрет смены пароля для администраторов: локальная версия — локальная
  группа «Администраторы» (SID `S-1-5-32-544`), доменная — «Администраторы
  домена» (RID 512) и локальная группа.

**Прочие меры безопасности**
- Нейтральные сообщения об ошибках (защита от перечисления логинов).
- ViewState подписан (MAC) и зашифрован.
- Заголовки безопасности: HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy.
- Cookie сессии: HttpOnly + Secure + SameSite.
- Скрытие версий IIS и ASP.NET.
- Ограничение размера запроса.
- Пароли не записываются в журнал.

**Логирование**
- Все действия пишутся в журнал событий Windows (источник `RDWebPassChange`):
  успешная смена, неудачная попытка, попытка смены пароля администратора,
  блокировки.

**Деплой**
- Скрипт `deploy-selfportal.ps1` (самоповышение прав, создание пула и
  приложения IIS, регистрация источника журнала).
