# SelfPortal — смена пароля локального пользователя Windows

Веб-приложение на IIS (ASP.NET Web Forms, C#) для самостоятельной смены пароля
локальной учётной записи Windows Server, в том числе **истёкшего**.

## Логика работы

Пользователь открывает форму, вводит имя пользователя, текущий пароль и новый
пароль дважды. Приложение выполняет смену через системный интерфейс Windows
(WinNT-провайдер):

```
WinNT://./<имя_пользователя>,user → ChangePassword(старый, новый)
```

Смена аутентифицируется старым паролем, поэтому не требует прав администратора
и работает для истёкшего пароля.

### Порядок обработки запроса

1. Проверка HTTPS (принудительный редирект на защищённый канал).
2. Проверка блокировки IP-адреса.
3. Валидация имени пользователя (только локальное имя, без `DOMAIN\` и `@`).
4. Проверка, что новый пароль не совпадает со старым.
5. Проверка сложности нового пароля.
6. Проверка подтверждения пароля.
7. Проверка CAPTCHA (если включена).
8. Смена пароля через WinNT-провайдер.

### Защита от перебора

- **CAPTCHA** включается после первой неудачной попытки.
- **Блокировка по IP**: 5 неудачных попыток → 30 минут.
- **Блокировка по учётной записи**: 10 неудачных попыток → 60 минут.
- Счётчики хранятся в `MemoryCache` (в памяти процесса).

### Защита административных учётных записей

Смена пароля запрещена для членов локальной группы «Администраторы»
(SID `S-1-5-32-544`). Проверка по SID не зависит от локализации системы.

### Прочие меры безопасности

- Нейтральные сообщения об ошибках (защита от перечисления логинов).
- ViewState подписан (MAC) и зашифрован.
- Заголовки безопасности: HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy.
- Cookie сессии: HttpOnly + Secure + SameSite.
- Скрытие версий IIS и ASP.NET.
- Ограничение размера запроса.
- Пароли не записываются в журнал.

## Логирование

Все действия пишутся в журнал событий Windows (Event Log), источник
`RDWebPassChange`: успешная смена пароля, неудачная попытка (с причиной),
попытка смены пароля администратора, блокировка IP или учётной записи.
Пароли в журнал не попадают.
